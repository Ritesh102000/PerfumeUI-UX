# EditoVerse

EditoVerse is a responsive landing page for an on-demand video-editing service. It presents four 60-second reel packages, a scroll-driven 3D pricing carousel, agency and creator benefits, and a project enquiry form.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

The project is designed for Vercel with the repository root directory set to `editoverse`.

- Production domain: `https://editoverse.catapultaiwork.com`
- Framework: Next.js
- Build command: `npm run build`

The contact form is currently a front-end demonstration and does not send data to a backend.
