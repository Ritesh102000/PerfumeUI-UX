# Phở 29 restaurant concept

A six-page UI/UX demo for a Vietnamese restaurant in Discovery Bay, built with React, TypeScript, Vite and Remotion. This folder contains compiled static output, mounted at `/pho29-demo/` in the showcase.

Pages: Home, Menu, About, Gallery, Contact and Order pickup. All six have directly loadable HTML entrypoints. The menu contains 70 source entries: 15 have matched original restaurant photos and 55 have clearly labeled dish illustrations. The gallery has 16 original-site photos.

Silent illustrations start and repeat automatically without playback controls; reduced-motion preferences show completed drawings. Phone pickup, directions, address, hours and email are prominent. The contact form prepares an email draft; no orders, payments or emails are submitted by the demo.

## Preview

Serve the showcase root over HTTP and open `/pho29-demo/`. Assets and navigation are built for this mount path.

## Content

Business details, menu prices and food images were sourced from https://pho29discoverybay.com on 19 September 2026. This is an independent website concept; the restaurant's existing website has not been changed. Image provenance beyond the source website was not independently verified. Prices and availability need restaurant confirmation before a production replacement.
